# Project guidance

- Mock data lives in `src/data/mock.ts`; the app currently has no backend and uses demonstration data only.
- App-specific UI lives in `src/components/app/`; shared navigation and the cart are mounted in `src/routes/__root.tsx`.
- The app uses a dark-only interface with gold and burgundy brand colors defined in `src/styles.css`.
- Never edit `src/routeTree.gen.ts` manually; it is generated by TanStack Router.
